# 07 · 部署与比赛流程

## 本机开发环境（一次配置）

1. 安装 VS2022 BuildTools（C++ 桌面开发，含 x86 工具链）——已装
2. 解压官方平台到 C:\Strategy（运行 `D:\SIM5_platform\SIM5Installation_2023.exe`）
   - 注意：老 exe 可能被杀软隔离，装完确认 `C:\Strategy\SimuroSot5.exe` 存在
3. 构建策略：见 README「快速上手」

## ⚠️ Device Guard / 智能应用控制

本机若开启 Device Guard（WDAC）或 Smart App Control，新编译的 exe/dll 可能被拦截
（报错「已被组织用 Device Guard 阻止」）。处理：

- Windows 安全中心 → 应用和浏览器控制 → 智能应用控制 → 关（或改为评估）
- 或给 `D:
obcup5v5足球仿真组小型\strategy_5v5uild` 加 Defender 排除目录
- 比赛用电脑如同样拦截，提前用「开发者模式」或关闭策略，并现场演练一次

## 日常开发循环

```bat
:: 编译
cmake --build build --config Release

:: 冒烟测试
build\Release\offline_test.exe

:: 拷贝到平台目录
copy /Y build\bin\Release\Strategy4Blue.dll C:\Strategy\
copy /Y build\bin\Release\Strategy4Yellow.dll C:\Strategy\

:: 启动平台（双击 C:\Strategy\SimuroSot5.exe），Start 开赛
```

平台操作注意（手册原文）：**比赛进行中不要动鼠标键盘**；平台自动摆位/判罚/记录日志。

## 比赛日 FAQ

- 队名没显示 / 机器人不动 → DLL 没被加载。先查 VC++ 2010 运行库（见上），再查位数 / mangled 名 / 路径
- 平台闪退 → 检查 DLL 是否 32 位、是否依赖了缺失的 MSVC 运行时（用 /MT）
- 需要调参 → 中场休息替换 DLL（文件名不变），其余时间平台锁鼠标
