# 02 · 平台接口说明（兼容性红线）

> 平台：SimuroSot5.exe + WorldModel.exe（Havok 引擎，2003 年起，Griffith University）
> 模板源码：官方安装包内 `src/Strategy4Blue|Yellow/`（VS2010 工程）

## 1. 部署结构（官方固定）

```text
C:\Strategy\
  ├─ SimuroSot5.exe / WorldModel.exe / Referee.dll   ← 官方，不动
  ├─ blue\Team1.dll / yellow\Team2.dll               ← 裁判代理，不动
  ├─ Strategy4Blue.dll      ← 我们替换（文件名不能改）
  ├─ Strategy4Yellow.dll    ← 我们替换（文件名不能改）
  └─ src\                   ← 官方模板源码（参考）
```

平台通过 `C:\Strategy\` 下的 `Strategy4Blue.dll` / `Strategy4Yellow.dll` 加载两队策略。

## 2. 五个导出接口（必须实现，签名一字不能改）

```cpp
STRATEGY4BLUE_API void SetFormerRobots(PlayMode gameState, Robot robots[]);       // 先摆方摆位
STRATEGY4BLUE_API void SetLaterRobots(PlayMode gameState, Robot formerRobots[],   // 后摆方摆位
                                       Vector3D ball, Robot laterRobots[]);
STRATEGY4BLUE_API void SetBall(PlayMode gameState, Vector3D * pBall);             // 发门球设球位
STRATEGY4BLUE_API void RunStrategy(Environment *pEnv);                            // 每周期决策
STRATEGY4BLUE_API void SetBlueTeamName(char* teamName);                           // 队名
```
黄队同名接口（`SetYellowTeamName`）。调用时机：
- 比赛开始：先 `SetXXXTeamName`（平台控制台显示队名，不显示=没连上）
- 判罚后：按规则先/后调用 `SetFormerRobots` / `SetLaterRobots`，门球再调 `SetBall`
- 无判罚的每个周期：调 `RunStrategy`

## 3. 核心数据结构（官方定义）

```cpp
typedef struct { double x, y, z; } Vector3D;
typedef struct { Vector3D pos; double rotation; double velocityLeft, velocityRight; } Robot;
typedef struct { Vector3D pos; double rotation; } OpponentRobot;
typedef struct { Vector3D pos; } Ball;
typedef struct {
  Robot home[5];                 // 己方：读位置/朝向，写轮速
  OpponentRobot opponent[5];     // 对方：只读位置/朝向
  Ball currentBall, lastBall, predictedBall;   // 球三帧（平台已给预测）
  Bounds fieldBounds, goalBounds;              // 场地/球门边界
  long gameState;                              // PlayMode
  long whosBall;                               // 球权
  void *userData;
} Environment;
```

**控制方式**：差速轮。每周期写 `home[i].velocityLeft / velocityRight`（官方 demo 量级 ±100）。
**坐标系**：原点左下角 (0,0)，x 向右 y 向上，厘米、度。蓝队守右门、黄队守左门（镜像）。

## 4. ⚠️ 兼容性红线（踩了平台加载失败）

1. **必须 32 位**：WorldModel.exe 是 i386（2003 版）。`cmake -A Win32`。
2. **必须 MSVC**：官方 DLL 导出的是 C++ mangled 名（实测）：
   ```
   ?RunStrategy@@YAXPAUEnvironment@@@Z
   ?SetFormerRobots@@YAXW4PlayMode@@QAURobot@@@Z
   ```
   平台按这些名字 GetProcAddress。MinGW/GCC 的 mangling 不同 → 加载失败。
3. **不能加 extern "C"**：会导出未修饰名，平台找不到。
4. **签名保持**：参数类型/顺序变 → mangled 名变 → 加载失败。
5. **不要依赖 MSVC 动态运行时**（/MT 静态链接，避免平台无 vcruntime）。

## 5. 比赛日志（.rlg）与复盘

- 文件名：`YYYYMMDDHHMMSS-5-黄队名-蓝队名.rlg`，存于 C:\Strategy\
- 格式：二进制，每帧 352B（蓝5机 + 黄5机 + 球 + gameState + whosBall，全部 IEEE-754 double）
- 日志坐标 x 偏置 -15（球门线在 x=-15/235），解析时 +15 对齐策略坐标
- 复盘：`python tools/py/rlg_analyzer.py xxx.rlg --csv out.csv`
