# 08 · 5v5 仿真足球战术库（agent 可执行版）

> 用途：把传统足球战术内化成**代码可直接落地**的规则，队友用 agent（Claude/Codex）改代码时按此对照。
> 坐标：cm/度，蓝队守右门(x=220)；1 号守门员；控制量 vl/vr（差速轮）。
> 数据驱动：每次改战术前先复盘 .rlg（rlg_analyzer），用数据说话，不瞎调。

---

## 1. 阵型体系（站位点配置 → situation.cpp / formation.cpp）

平台有 4 个站位点：assist(助攻) / mid(中场) / passive(防守)，由 role_assignment 分配角色后各占一位。
**核心原则：任何时候不能让 5 人全挤在中后场（复盘发现的最大问题）。**

| 阵型 | 配置 | 适用 |
|------|------|------|
| 1-2-1-1（默认）| GK + 2 DEF(passive/盯人) + 1 MID + 1 FWD(active/assist) | 均衡 |
| 1-3-1 | GK + 3 DEF | 落后/防守 |
| 1-1-2 | GK + 1 DEF + 2 FWD | 追分/进攻 |

**铁律**：
- 球在中场时，**至少 1 台前压到 x 中线前（进攻方向 20cm 内）**争球
- 站位点必须**随球动态更新**（situation.update_stand_points），不能是固定死点
- 己方罚球区最多 1 人（守门员）+ 1 名清道夫，禁止堆叠（=送点球）

## 2. 防守战术（defense.cpp / roles.cpp / situation.cpp）

### 2.1 区域防守（zonal，主战术）
- PASSIVE 站"球-己方球门连线"上，距门约 50cm（现状已有）
- **但必须避开大禁区**（已修），球在禁区附近时外拉至 85cm

### 2.2 高位逼抢（press）
- 球在**对方半场**时，防守点**前压**（不能全缩回自己半场）
- 目的：把战火留在对方半场，减少己方门险
- 实现：passive 点 x 下限随球位置前移

### 2.3 盯人（man-marking）
- 对方持球/最危险球员分配 1 台贴身（距 10-15cm 跟随）
- 实现：role_assignment 加"盯人角色"，目标=对方 ACTIVE/离球最近者

### 2.4 补位（cover，清道夫）
- 守门员外的最后 1 台，站"球门-球"连线中点偏门，防止被单刀
- 现状 passive 基本承担此职，注意与守门员不重叠

### 2.5 延缓（delay）
- 对方持球推进时，最近的 1 台**逼近但不抢**（减速对方，等队友回防）
- 实现：run_passive 距持球人 <20cm 时改为"跟跑站位"，不盲目冲抢

### 2.6 禁区纪律（防送点，最高优先）
- 己方大禁区最多 2 人（守门员+清道夫）
- 防守机器人的目标点**永不进入己方大禁区**（已修 passive/assist）
- 球进禁区：守门员优先扑球，其他人**只封角度不贴身**

## 3. 进攻战术（shoot.cpp / pass.cpp / roles.cpp）

### 3.1 拉开宽度与纵深
- 无球进攻队员站**边路+纵深**（y 方向拉开 30cm+），给持球人出球点
- 现状 assist 点偏保守（球前 25cm），可加大到 40cm 且 y 错开 30cm

### 3.2 三角传递
- 持球人 + 2 个接应点构成三角形（一个近、一个远），传球有选择
- 实现：pass 选队友时考虑"接应点质量"（是否被盯、路线是否干净）

### 3.3 射门决策
- 距门 <70cm 且角度 >30°（门柱-球连线夹角）→ 射门
- 守门员偏离球门中心 → 射远角
- 角度太小 → 回传/横传找更好位置（避免打守门员身上）

### 3.4 反击（攻防转换）
- 夺回球权瞬间：ACTIVE 立即前插，传球优先给最靠前的队友
- 实现：situation 检测 whosBall 切换 → 下一周期站反击点

## 4. 攻防转换（strategy.cpp 主调度）

**丢球瞬间**：球权从我们→对方，立即切换防守（威胁等级提高，站位回撤）
**夺球瞬间**：球权从对方→我们，立即切换进攻（威胁等级降低，前压）
现状：situation.analyze 每周期重算，无记忆 → 转换瞬间响应延迟 1-2 周期，可接受但可优化

---

## 5. 定位球（formation.cpp，12 PlayMode）

- 开球（PlaceKick）：按规则摆位，**开球后至少 1 台立刻冲向球**（避免开局丢球权）
- 门球（GoalKick）：守门员开球，摆位注意别越位
- 点球（PenaltyKick）：攻防双方按规则站位
- 争球（FreeBall）：抢占球落点

## 6. 仿真特化（本平台特有约束）

| 特化 | 影响 | 应对 |
|------|------|------|
| 差速轮 | 转向慢、到点 overshoot | 提前转向、减速逼近（motion 已做） |
| 无通信 | 队友位置只能靠上帝视角推算 | 站位点全局共享，角色分配防抖（-8 惯性）|
| 40Hz 决策 | 每周期 25ms 内决策 | 算法保持 O(5) 简单 |
| PlayMode 状态机 | 判罚打断流程 | strategy 先查 gameState |
| 判定规则 | 禁区/推球/僵局判罚 | 防守纪律优先（见 2.6）|
