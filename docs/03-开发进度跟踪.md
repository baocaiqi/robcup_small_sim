## 第 14 轮（2026-08-31）— 防守结构性改造（借鉴官方 demo CenterDefender 球-门连线思想，自研实现）

### 读官方 demo 源码（Strategy4Yellow.cpp）提炼的防守思想
1. **CenterDefender（中卫）永远钉「球-门连线」**：球远(x>130)站中场 (110,90) 护门；
   球贴边站 (ball.x-45, 90)（球后 45cm 中路）；球进门前(x<25)站 (25, ball.y) 门前护线
2. **全队防守收缩**：球回本方半场时 4 个外场球员全部回到球-门连线之间的区域
3. **Goalie**：球过中线站门中央；球回本方按球 y 分区站位（不是死守一点）；球贴门(x<12)出击

### 我方机制缺口（2 场 2:7 逐帧复盘确认）
1. **球-门连线无人钉守**：球控停门前 (205,90) → threat=1.0 → passive 走人盯人，但盯人
   站位被 `in_penalty_area → 85cm 线` 推出；double_team_point 球进罚球区直接 return false
   → **门前只剩门将 1v1**，demo 追击手从 100cm 外直冲抢点，途中无任何我方拦截
2. **区域防守纪律过严**：plan_defense 断球点、double_team 夹抢点一落罚球区就被推出，
   防线压不上去，禁区内空虚

### 改动（借鉴 demo 思想，全部自研实现）
1. **defense.hpp/cpp 新增 `goal_cover_point()` 球-门连线护门点**：
   - 球距门 >100cm：球-门连线、球向门方向 45cm（对应 demo 中卫 ball.x-45）
   - 球距门 45~100：门前 50cm 拦截线、y 跟球（压上断球）
   - 球距门 <45：门前 20cm 线、y 跟球（堵射门角度，对应 demo 门前 25cm）
   - 不做禁区纪律（防守方进己方罚球区合法），只 clamp 场地边界
2. **roles.cpp run_passive 门前协防分支**（置于人盯人之前）：
   - 触发：球在门前 80cm 内 **且** 球近静止(<3cm/帧) **且** 对方已逼近(<60cm)
   - 站位：goal_cover_point() —— 卡死对方直冲门前的路径，与门将双人包夹
   - 与第 13 轮撤销的"门前保护"区别：**加"对方逼近<60cm"条件**——我方门球/清球
     场景（对方离球远）不触发，不拉离防区（上次 sim -3.5 的根因）
3. **defense.cpp double_team_point 解锁禁区纪律**：
   - 球进己方罚球区不再 return false：持球者已压到门前 45cm 内 → 允许第二人进禁区协防
   - 夹抢点由"落罚球区推出 85cm"改为"落门区(小禁区)推出 55cm"——罚球区内允许
