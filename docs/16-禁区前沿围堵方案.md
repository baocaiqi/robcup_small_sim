# 16 · 禁区前沿围堵——治官方冲禁区推球（防守摆位修正）

> 状态：**已实施（2026-09-09）**：offline_test 25 组全绿 + sim A/B 记录
> （docs/06 第 39 轮）；真机验证待办：观察 demo 是否还被压到门前推球。
> 维护：D 模块（防守/摆位），联动 A（threat 分级）。
> 现象（用户实测 vs 官方 demo）：demo 反复高速带球**直冲我方禁区推球**，
> 被判犯规/冲撞门将 → 比赛碎片化，我们被动。对策：**禁区前沿提前围住**。

## 1. 现状根因（代码级）

规则边界（docs/00）：
- **小禁区/门区**（球门前 50cm 带，蓝 x∈[170,220]）：只许守门员 1 人；
  非门将进入 = 门区 2+ 人 → 罚点球（硬红线）
- **大禁区**（球门前 50~80cm 带，蓝 x∈[140,220]）：非门将 ≤3 人合法

当前防守代码的钳制**把大禁区一并清空**（口径偏保守）：
- `roles.cpp` 人盯人站位：`in_penalty_area` → 推出大禁区外沿 x=135
- `defense.cpp` plan_defense：断球点 `in_penalty_area` → 同样推出 x=135

后果：门前 135~170cm 成**无人走廊**。demo 高速带球（球不静止）→
goal_cover_point 协防分支（要求球速<3）不触发 → 人盯人被推出禁区 →
**门前只剩门将 1v1**，demo 直通门区推球/撞门将，反复判罚或丢球。

## 2. 方案：大禁区放行 + 禁区前沿双人围堵

把防守动态目标钳制从「大禁区外沿」修正为「小禁区前缘外 2cm」，
让防守者合法进入大禁区中部拦截（docs/03 第14轮 double_team 已放行先例）：

1. **钳制口径统一**（核心）：
   - 人盯人站位 / plan_defense 断球点 / 兜底点：`in_goal_area`（小禁区）→
     推到小禁区前缘外（蓝 x≈165~168）；**大禁区放行**（≤3 人天然满足）
   - 静态锚点（situation.cpp）保持禁区外不变（无球站位不占拦截位）
2. **双人围堵提前**：double_team 触发距离 100→145cm（demo 距门 ≤145 即合围），
   与盯人者形成「正面挡 + 侧面封」口袋；夹抢点本已钳制在小禁区外 ✓
3. 红线不变：小禁区只有门将；防推球（距球 ≥8cm）、对方门区禁入等纪律保留

## 3. 实现（2026-09-09 落地）

1. **defense.cpp plan_defense**：删「大禁区推出」（原 in_penalty_area → 85cm=x135），
   保留小禁区钳制（in_goal_area → 55cm=x165）+ 防推球距球 ≥8cm 兜底
2. **roles.cpp 人盯人站位**：`in_penalty_area` 推出 → `in_goal_area` 推出（同 55cm 口径）
3. **double_team_point**：删门槛③（球在己方罚球区且持球者距门>45 不协防——与大禁区
   放行矛盾）；kDoubleTeamDangerDist 100→145（demo 距门 145cm 即第二人合围；
   125 变体 A/B 无改善且 seed1 更差 → 定 145）
4. **sim_bench**：新增「己方门区非门将」统计（防守侧监控，均 ~2400 帧/场——
   **甄别后确认非违规**：其主体是 goal_cover 贴门双人堵门的刻意战术；规则判罚
   主体是**进攻方在对方门区**聚集（docs/00 L46 门球条款、sim_bench ga 统计口径），
   防守方在自己门区+门将不判（demo 中卫站门前 25cm 同理））

## 4. 验证结果（2026-09-09）

- offline_test 25 组全绿，新增 test_box_edge_block 4 断言：
  断球点/夹抢点可进大禁区(>135)但绝不进小禁区(≤168)、距球≥8cm、
  double_team 在持球者距门 120cm（旧 100 不触发）与大禁区内带球均触发
- sim A/B（50 场×seed1/2，scripted 2.0，带 PlaceKick 模拟）：
  | 版本 | seed1 | seed2 | 控球 s1/s2 |
  |---|---|---|---|
  | P1 基线 | 4.1:4.0 | 4.7:3.9 | 31.0/31.6 |
  | **围堵版(145)** | 4.0:4.1 | 4.5:3.7 | 31.8/31.9 |
  净胜 ±0.1~0.2（噪音内不回退），控球 +0.3~0.8（demo 推进被提前破坏的信号）
- 真机（待办）：观察 demo 冲禁区是否被挡在大禁区（球不再被压到门区推球）

## 5. 风险

- 大禁区 4 人违规：assist/mid/passive 分支互斥（人盯人/double_team/兜底各 1 人），
  加 sweeper 也站中场 → 同时在大禁区非门将 ≤3 ✓（offline 冒烟验证计数）
- 门区 2+ 人：所有动态目标小禁区前缘钳制，追球路径穿门区场景已有门前锥形
  区夹取（run_active/run_assist），保持
- 己方门区双人堵门（goal_cover 贴门段）为刻意战术，规则不判防守方（见上）；
  若真机实测平台按「门区 2+ 人不分攻守」判罚 → 回退该分支并记录
