## 3. 待办（按优先级，含代码位置 / 实测依据 / 已试过什么）

### P0 门将横向跟不上门前横移（**最新一球就是这个**）
- 证据（`20261008162741-5-Hnnu-BENCH-T1.rlg` 唯一失球 @帧1313）：球沿我们门线横移，**y 以 1.6cm/帧（≈64cm/s）爬升**；门将 y **滞后且偏错侧**——球 y=76.7 时门将 83.2，球到 81.5（过线）时门将 **89.8（偏 8.3cm 在球上方）**；对方最近者 y=84 就在球上（是对手把球沿门线推着走）。
- 结构问题：门将 y 带 `[kGkYLo=74, kGkYHi=106]`，而**门框是 70~110** ⇒ 球在 70~74 / 106~110 时门将**物理上够不到**（1289–1304 期间球在 y=59~67，门将被压在 74）。
- **改法**：门前横移目标改用「预测进门点」`y_at_goal`（**现成机器**：`kGkPredictBlock` / `gk_block_cy` / `predict_y_at_x`），并 `TM_PASS` 全速；注意门前几条闸（`gk_rule_goal_line_hold` 的滑移分支、我加的闸四）现在都**不预测**、只保当前位置。另：把 `kGkYLo/kGkYHi` 放宽到 **70/110**（两个值被很多规则引用，改完必须跑全量测试）。

### P1 出球方向曾指向自家门（"先让开/擦过球"的真因）
- 证据（`20261008160233-5-Hnnu-BENCH-T1.rlg` 第 2 球 @3506）：反推 `pdiry≈−0.75` ⇒ 推穿目标 ≈ `(44, 43.9)`，而球在 `(14.7, 77.7)`、**底柱 y=70 只差 7.7cm** ⇒ **方向本身朝自家门底角**。门将从 (5.3,75.1) 冲到 (23.9,82.5)，**从球旁 5~7cm 掠过**、没顶到球，球从它身后进网。
- **改法（与既有测试契约兼容）**：给 `gk_reachable_dir` 加**半平面约束**——球 `y<90` 时只许 `pdiry>=0`；球 `y>90` 时只许 `pdiry<=0`；并要求 `pdirx*attack_dir>0`。约 4~6 行。
- ⛔ **千万别做**：把推穿方向强制成 `ax=attack_dir, ay=0`。**试过两次，都会打坏三条测试**：
  - `test_goalie_clear_push`（`offline_test.cpp:2080`，断言 L2101）**自己调用 `gk_restart_direction` 取出球方向**，把门将摆在「球后 10cm（沿该方向）」并把机头对准它，然后断言 `v1>=30`。强改方向 ⇒ 机头不匹配 ⇒ `gk_turn_to` 一直原地转 ⇒ **`v1=0`**。
  - `test_goalie_straight_clear`（断言 L2144）同理。
  - `test_gk_goal_kick_reach`（断言 L3994：门球 200 帧内必须触到球）——加"推穿前横向对准球的 y（±3cm）"门槛会让它**永远对不上**（门球摆点 y=66/72 在门将 y 带 74~106 之外）。改用 clamp 后的可达 y 仍未通过；**根因未定位**。

## 5. 铁律与坑（本轮踩过的，务必照做）

1. **旋钮声明顺序**：`TUNABLE(kGk*)` 必须在**使用点之前**。`gk_rule_ball_behind` 在 L421，若旋钮声明在其后 → **编译失败**（我犯过两次）。现在所有 `TUNABLE(kGk*)` 已集中在门将函数区之前。
2. **文件编码**：仓库文本是 **CRLF / UTF-8 无 BOM**。用 python 改文件必须探测原换行并 `io.open(f,'w',encoding='utf-8',newline='')`；否则整个 diff 被污染（BOM 也检查过）。
3. **不要用 PowerShell here-string 承载 Markdown/中文内容**：内容里的 `---`、中文引号会把 here-string 打断，命令**整条不执行**（我白跑过数次）。**改成：用 write 工具落一个 .py 脚本文件，再 `python 脚本`**。
4. **Python / PowerShell 字符串里不要嵌 ASCII 双引号**：`"0=不要求"到了"..."` 会直接语法错误 → 脚本没跑，而"构建成功 / 测试绿"是**旧代码的假绿**。**每次 patch 后必须确认打印了 `PATCHED`**。
5. **锚点不要跨行到中文注释**（如 `if (gk_turn_to(...)) return true;    // 中文`）：只写 ASCII 部分会不匹配。用**单行、纯 ASCII、唯一的**锚点最稳。
6. **部署纪律**：先 `Copy-Item $dst $bk`（**备份在前**）→ 覆盖 → 核 `pe_exports`（i386 + `SetYellowTeamName`）→ 查二进制**无** `goalie_trace`/`hnnu_blackbox`/`g_gk_rule_probe`（比赛版不许写盘）→ 查新旋钮在不在。**曾经把备份做在覆盖之后**，得到的"备份"其实是新版，别再犯。
7. **平台运行中也能覆盖 DLL**（Windows 允许替换映像），但**必须重启平台才生效**。
8. **改完必须跑全量测试；红了就 `git checkout -- src/...` 回退，绝不提交/部署红的构建。**
