# 04 · 代码规范与算法详解

## CoopPass 统一接球任务（2026-09-20）

- `WorldModel::coop_pass_task` 保存传球人、接球人、固定坐标和剩余寿命。主攻通过安全及准备点检查后发布，后续仅按球位更新指向该点的方向。
- 指定接球人跳过普通避敌、分散与间距调整，直接执行保存点；其他队员不变。紧急护门、高威胁、明确对手控球、点球、角区和门区纪律优先取消任务。
- 最长保持 80 次主攻执行（约两秒，避免角色长期被占住）；普通散球不会取消。比赛状态变化、线路/接球点不安全也会取消。
- 配合传球不受射门次数额度阻塞，也不增加射门次数。普通 PassPlan 和射门计次规则保持原样。
- 生命周期分为 Preparing（准备/推动）、Receiving（实际出球后接应）、Received（已接稳）。推球命令只开启观察窗口，后续帧须有沿传球方向位移、速度和球人分离证据；Receiving 不再检查新算出的球到接球点线路，也不因散球触发普通回防。
- 连续观察接球人贴球、球速放缓、最近己方身份及球权证据才结束接球任务；固定编号不变，实际接球人临时带球，1号让位。临时带球不调用普通 PassPlan 或射门评分；失球、别人明确接管、比赛切换或危险时恢复普通角色。
- 普通回防阈值仍在，但有效接球/临时带球在 0.3≤威胁<0.6 时优先；高威胁、门前紧急危险及纪律始终优先。主攻停车前仍维护门区计数和射门冷却。
- Preparing 等待阶段通过 `pass_opponent_arrives_first()` 比较锁定接球人与五名对手到锁点的预计时间。对手速度只取朝锁点的投影做短期外推，背离锁点会增加而不是缩短预计时间；仅明显领先安全余量才由统一取消器记为 `OpponentFirst`。既有安全原因先判，Receiving 阶段不再使用该规则。
- 接球动作按阶段分流：Preparing 与 Receiving 远球继续普通锁点走位；Receiving 近球先原地面向来球，再按球距缩小共同前进量，差速转向量保留。锁点仍保存不变，但若它位于机器人侧面，差速车暂时停车迎球；只有锁点在机头前后可直行/倒行时才低速补位。可信且确实逼近的球速用于计算迎球朝向，低速/异常/背离时退回朝当前球位置，再退化则用锁定传球方向。该动作层不修改接稳阈值或临时控球流程。
- 出球与接稳判断阈值待仿真/真机标定，离线测试不能证明实战成功率。规格见 `docs/work/coop-pass-task-spec.md`。

## 代码规范

- 头文件放 `include/simuro5/`，实现放 `src/`；命名空间 `simuro5`
- 注释中文；每个文件头注释写"移植自/重写"来源
- 常量集中在 `team.hpp` / `field_info.hpp`；调参数值集中在各模块顶部注释标注
- 不要 `using namespace` 在头文件；接口函数（dll 壳）保持官方签名
- 新增模块：先写 .hpp 接口 → 实现 → offline_test 加用例 → 跑通再提交

## 算法详解

### 1. 差速轮控制（motion.cpp）—— 官方 demo Position() 移植

```
输入: 机器人 (x,y,rot), 目标 (tx,ty)
1. desired_angle = atan2(ty-y, tx-x)   // 指向目标
2. theta_e = 归一化(desired_angle - rot)
3. drive = vc * (sigmoid(d) - 0.3)      // d 大→接近满速, d 小→减速
4. vl = drive - Ka*theta_e; vr = drive + Ka*theta_e   // 角度误差修正转向
5. |theta_e|>95° 时倒车走；Ka 随距离分段增大（近处纠偏强）
```
调参点：vc（基准速度）、Ka 分段表、到位阈值（d<5）。

### 2. 角色分配（role_assignment.cpp）—— 效用函数分配

```
4 个非门将机器人抢 4 个角色（ACTIVE/PASSIVE/ASSIST/MIDFIELD）：
效用 = 到角色参考点的距离 - (当前已是该角色 ? 8 : 0)   // 惯性防抖
贪心：按 ACTIVE→PASSIVE→ASSIST→MIDFIELD 顺序选效用最低的机器人
```
参考点由 situation 每周期更新：active=球、passive=球-门连线拦截点、assist=球前方侧翼、mid=中线。

### 3. 射门（shoot.cpp）

- 条件：球距对方球门 <70cm
- 瞄准：门柱内侧两选一，选离对方守门员远的一侧（gap 大者）
- 执行：跑到球后方 8cm、方向对准开口（没有 kick 动作，靠带球冲）

### 4. 传球（pass.cpp，简化版）

- 选离对方球门最近的队友；距离 <60cm 且球→接应点路线无对手（点-线段距 <15cm 算挡）
- 执行：带球向接应点推进

### 5. 防守（defense.cpp）

- 站位点 = 球与己方球门连线上、距球门 50cm（situation 已算）
- 门区/禁区修正：不进己方门区（守门员专属）+ 不越罚球区逗留

### 6. 摆位（formation.cpp）—— 规则映射

| PlayMode | 先摆 | 后摆 |
|----------|------|------|
| PlaceKick(开球) | 进攻方：中圈+己方半场 | 防守方：己方半场除中圈 |
| FreeBall(争球) | 1 人球侧 25cm（估球位） | 按平台给的球位摆 |
| PenaltyKick(点球) | **防守方**：守门员门线+队友中线另一边 | 进攻方：罚球人球后 10cm |
| FreeKick(任意球) | 进攻方：罚球人球后 10cm | 防守方：门前+己方半场 |
| GoalKick(门球) | 发球方：守门员门区+队友门外 | 防守方：门前+己方半场 |

> 注：官方 demo 摆位部分不符合 2025 规则（如开球越过中线），本库已按规则修正；
> 现场以裁判执行为准，需要实测校准。
