# 抢断改造方案（全局竞标 + 补位交接 + tackle 三硬规则）

> 状态：**方案待确认**（未实现）。参考「预期价值（EV）决策 / 协防补位」的通用防守战术思想，
> 落到我们自己的 `defense.cpp` / `roles.cpp`，自研实现（原创红线，不拷贝任何第三方代码）。

## 一句话目标

把现在**分散在三处、各自独立判断**的「抢断」（`run_mark_body` 逼抢、`run_passive` 争抢、
`double_team_point` 夹抢），收成一个**每帧全局唯一决策**：只让「该抢的那个人」出手，其余人
守住自己的盯人位；抢的人把原盯人「租出去」，没补位就不出脚；出脚前必须对齐、卡内线、能协防就先等。

## 背景：为什么现在会漏人（2026-10-03 真机 1:2 复盘）

丢球不是「匈牙利配错人」（人都盯上了，后卫离球 14~18cm），而是**「贴上了但抢不下来 + 抢的时候身后漏人」**：

1. 三个抢断入口各自判断，没有全局统筹 → 多个人同时扑球，一起被过、身后没人补。
2. 抢断是 `chase_ball` 直冲球，**没对齐朝向、没卡内线、没等协防** → 正面对冲被变速过掉。
3. 抢断者上前后，他原来盯的人（`mark_assign` 目标）就漏了 → 对方直塞身后。

## 现状代码锚点（改这三处）

- `src/roles.cpp` `run_mark_body`（~1720）：被盯者控球 → `chase_ball`（逼抢）
- `src/roles.cpp` `run_passive`（~1832）：`my_d < mate_d` 谁近谁抢（争抢上抢）
- `src/defense.cpp` `double_team_point`（~555）：谁近谁上去夹（夹抢）
- `src/defense.cpp` `assign_marks`（~461）：匈牙利盯人分配（**不动**，只读它的 `mark_assign`）

## 阶段 1：全局唯一竞标（谁去抢）

### 目标

每帧算一个全局最优的「抢断者」，只让他出手，其余防守者保持自己的盯人站位。

### 新增函数

```cpp
// 抢断可行性评分：对每个候选防守者 i，算「这一抢划不划算」的期望价值 EV。
//   gain = 成功率 × 夺回球权价值；loss = 失败率 × 我失位后露出的威胁；再减换人折腾 λ。
//   只让 EV 最高且 >0 的那个人出手（全局唯一，写回 wm.stealer_id）。
//   —— 取代 run_passive 的 my_d < mate_d（谁近谁抢），从「就近」升级为「该不该抢」。
double steal_ev(const WorldModel &wm, int i);       // 内部，见下
void   steal_decide(WorldModel &wm);                 // 每帧调一次，写 wm.stealer_id
```

### EV 公式（可实现的版本）

```cpp
double steal_ev(const WorldModel &wm, int i) {
    double d_ball = dist(me, ball);                              // 我到球多远
    double opp_spd = hypot(ball.vx, ball.vy);                    // 球速（≈ 对手带球速度）
    double dribbler = nearest_opp_to_ball(wm);                   // 持球者
    bool   has_cover = (count_cover_within(wm, i, kStealCover) >= 1);  // 附近有队友能协防

    // 成功率：越近越容易、球越慢越容易、有协防越容易
    double p = 1.0 / (1.0 + exp(kStealA - kStealB * d_ball - kStealC * opp_spd + kStealD * has_cover));

    double gain = p * kStealValue;                       // 夺回球权值多少钱
    double loss = (1.0 - p) * exposed_cost(wm, i);       // 失败后失位露出的代价
    return gain - loss - kStealLambda;                   // λ 复用换人惩罚思想（防抖）
}

// 我失位后「原来盯的那个人」还危不危险：越危险越不该离开他去抢。
double exposed_cost(const WorldModel &wm, int i) {
    int t = wm.mark_assign[i];                            // 我盯的是谁
    if (t < 0) return 0.0;                                // 没盯人 → 抢了不亏
    return mark_threat(/* 复用 assign_marks 里对 opp[t] 的打分 */);
}
```

### 落地（改三处）

```cpp
void steal_decide(WorldModel &wm) {
    wm.stealer_id = -1;
    double best = 0.0;
    for (int i = 0; i < PLAYERS_PER_SIDE; ++i) {
        if (wm.role[i] != ROLE_PASSIVE && wm.role[i] != ROLE_ASSIST && wm.role[i] != ROLE_MIDFIELD) continue;
        if (i == wm.sweeper_id) continue;                 // 清道夫不动（保纵深）
        double ev = steal_ev(wm, i);
        if (ev > best) { best = ev; wm.stealer_id = i; }
    }
}
```

- `run_mark_body` 逼抢分支（~1720）：`chase_ball` 前加 `if (wm.stealer_id != id) 保持站位；`
- `run_passive` 争抢上抢（~1832）：整段条件里的 `my_d < mate_d` 换成 `wm.stealer_id == id`
- `double_team_point` 的「谁近谁去」（~585）：同样认 `wm.stealer_id`（或保留夹抢但让夹抢者不抢球、只封角度）

## 阶段 2：补位交接（抢了之后谁补）

### 目标

抢断者（stealer）上前后，他原来盯的人（orphan）不能被漏掉。要么有人接管，要么**放弃抢断、改封射门角度**。

### 逻辑

```cpp
// 抢断者出手时，把他的原盯人任务「交接」给离 orphan 最近且空闲的队友。
void steal_handover(WorldModel &wm, int stealer) {
    int orphan = wm.mark_assign[stealer];                 // 他原来盯的人
    if (orphan < 0) return;                                // 没盯人 → 不用交接

    // 找离 orphan 最近、且没在抢断的防守者
    int backup = -1; double best = 1e9;
    for (int i = 0; i < PLAYERS_PER_SIDE; ++i) {
        if (i == stealer || i == wm.sweeper_id || i == wm.stealer_id) continue;
        if (wm.role[i] != ROLE_PASSIVE && wm.role[i] != ROLE_ASSIST && wm.role[i] != ROLE_MIDFIELD) continue;
        double d = dist(wm.home[i], wm.opp[orphan]);
        if (d < best) { best = d; backup = i; }
    }

    if (backup >= 0) {
        wm.mark_assign[backup] = orphan;                   // 交接
        wm.mark_commit[backup] = kMarkCommit;              // 复用承诺帧，窗口内不许反悔
    } else {
        // 没人能接 → 放弃抢断，抢断者改封射门角度（站 orphan→球门连线），不出脚
        wm.stealer_id = -1;
        block_shot_angle(wm, stealer, orphan);
    }
}
```

### 关键护栏（「无补位，不出脚」）

- 抢断者出手的**前提**是 `steal_handover` 找到了 backup。找不到 → 不抢，改封角度。
- 这样从根上杜绝「抢断失败直接漏人」——抢断永远是「有人托底」才发生的。

## 阶段 3：tackle 三条硬规则（怎么抢才不被过）

### 目标

抢断动作本身（`chase_ball` 直冲球）太鲁莽，正面对冲被变速过掉。加三条闸门，三条**全部通过**才出脚。

### 三条硬规则（在 stealer 执行 `chase_ball` 之前判定）

```cpp
// tackle 三硬规则：三条全过才允许伸脚冲球，否则退回站位/压缩空间。
bool tackle_ok(const WorldModel &wm, int id, const BallState &ball) {
    const RobotState &me = wm.home[id];

    // ① 出脚前先对齐朝向：机头指向球的误差 < kTackleAngleTol，斜着冲会被晃
    double want = angle_to(me.x, me.y, ball.x, ball.y);
    if (std::fabs(angle_diff(me.rot, want)) > kTackleAngleTol) return false;

    // ② 卡内线（球门方向那一侧）：从内线出脚，把对手往外线（边线）赶，宁可放外线。
    //    我在场侧（外线）时不抢——从外线顶球会把球顶向自家门（历史 3:8 乌龙教训）。
    double ball_goal = wm.ctx.dist_our_goal(ball.x);
    double me_goal   = wm.ctx.dist_our_goal(me.x);
    if (me_goal > ball_goal) return false;               // 我在球外侧（离门更远）→ 不抢

    // ③ 队友 kTackleCoverHorizon 帧内能到位协防 → 延迟出脚，先压缩空间（逼他变向），
    //    而不是孤注一掷扑上去（扑空了就是单刀）。
    if (count_cover_within(wm, id, kTackleCoverHorizon) >= 1) return false;

    return true;
}
```

### 落地

- 阶段 1 里 stealer 的 `chase_ball` 前面套一层 `tackle_ok`：不通过 → 退回 `run_mark_body` 的站位（压缩空间），等下次判定。
- 三闸门都是「纯判读、无副作用」的纯函数，可单独单测（offline_test 加 3 条）。

## 新增旋钮（加在 `defense.cpp` 匈牙利旋钮旁边，统一管理）

| 旋钮 | 默认 | 含义 |
|------|------|------|
| `kStealEnable` | 1.0 | 总开关：0 = 回退旧分散抢断逻辑（三处 `my_d<mate_d` 原样） |
| `kStealDist` | 20.0 | 触发抢断：我到球最大距离（cm） |
| `kStealVMax` | 1.5 | 球速上限（cm/帧），超此速度不抢（高速带球易被过）⚠️需真机标定 |
| `kStealLambda` | 25.0 | 抢断换人折腾惩罚（cm，复用 λ 思想） |
| `kStealValue` | 40.0 | 夺回球权的价值（cm 当量，标定项） |
| `kStealA/B/C/D` | 2.0/0.3/0.5/0.8 | 成功率 sigmoid 系数（标定项） |
| `kStealCover` | 30.0 | 「有协防」判定半径（cm） |
| `kTackleAngleTol` | 15.0 | 规则①：出脚前机头-球夹角上限（度） |
| `kTackleCoverHorizon` | 20.0 | 规则③：协防到位预测帧数（≈0.5s） |

> ⚠️ `kStealVMax` 是坑位：真机是 cm/帧，0.6 m/s ≈ 1.5 cm/帧，而 demo 慢速带球 p50 已 1.8cm/帧，
> 会误把 demo 慢球判成「太快不抢」。**必须对着真机数据标**，不能照抄方案里的 0.6 m/s。

## 与现有模块的边界（重要，不耦合）

- **匈牙利 `assign_marks`（L1）不动**：只读它的 `mark_assign`。抢断是 L2 的「临时越权」——
  抢断者只是把盯人任务「租出去」，抢到或放弃都归还（阶段 2 的 handover 就是归还）。
- **主动截球 `early_intercept_point`（docs/15）不动**：它管「拦截飞行中的传球」，本方案管
  「抢脚下球」，两者互补不重叠；若将来要拦截传球线，直接复用 early_intercept_point，不新写。
- **门将 `run_goalie` 不参与**：门将是最后一关，抢断层只调度场上 4 个非门将。

## 风险与回退

- **最大风险**：`exposed_cost` 没算对 → 中卫扑上去、身后大海（这是 C_exposed 要防的，是核心项）。
- **回退**：单旋钮 `kStealEnable=0` 即恢复三处旧分散逻辑，零副作用。
- **增量**：阶段 1 → 2 → 3 每步编译 + `offline_test` + sim_bench A/B，绿了再下一步。
