# 00 · FIRA 仿真 5v5 规则速查

> 来源：`4.1赛事规则.FIRA小型组-FIRA仿真5vs5项目.2025中国机器人大赛暨RoboCup机器人世界杯中国赛.pdf`
> 规则细节以平台运行效果和现场裁判为准。

## 场地与器材（cm）

| 项目 | 数值 |
|------|------|
| 场地 | 220 × 180，围墙高 5 / 厚 2.5 |
| 中圈半径 | 25 |
| 球门宽 | 40（门线 y ∈ [70, 110]） |
| 门区（小禁区 A） | 球门前 50 × 15 |
| 罚球区（大禁区 A+B） | 球门前 80 × 35 |
| 点球判罚区 | 120 × 80（球进该区 → 进入点球判断） |
| 禁止推球区 | 场地四角黄色区域 |

## 坐标系（平台与策略交互）

- 原点 (0,0) 在**场地左下角**；x 向右，y 向上；单位 **厘米**；角度 **度**（非弧度）
- 蓝队守右门（x≈220 侧），黄队守左门（x≈0 侧）；**1 号机器人 = 守门员**

## 比赛流程

- 两个半场各 5 分钟，中场休息 10 分钟（球队未准备好可延 5 分钟，再不行判负 0-5）
- 半场交换场地；**蓝队获得开球权**，下半场黄队开球
- 只在中场休息/加时开始时可以换策略；比赛期间只允许裁判操作电脑
- 小组循环赛：胜 3 平 1 负 0；排名：净胜球 → 胜负关系 → 进球数

## 12 种比赛状态（PlayMode，代码中 enum）

| 值 | 名称 | 含义 |
|----|------|------|
| 0 | PM_PlayOn | 比赛进行中（RunStrategy 正常跑） |
| 1-4 | PM_FreeBall_LeftTop/LeftBot/RightTop/RightBot | 争球（1/4 场地） |
| 5/6 | PM_PlaceKick_Yellow/Blue | 开球（黄/蓝） |
| 7/8 | PM_PenaltyKick_Yellow/Blue | 点球（黄/蓝被罚） |
| 9/10 | PM_FreeKick_Yellow/Blue | 任意球（黄/蓝） |
| 11/12 | PM_GoalKick_Yellow/Blue | 门球（黄/蓝发） |

## 判罚规则要点（策略要主动规避）

- **点球**：门区内除守门员外停留 >20 周期 / 门区 2+ 人或禁区 4 人 → 罚点球（大坑！守门员必须独守）
- **禁止推球区推球**：犯规每 4 次给对方 +1 球；判争球
- **僵局**：门区外僵持 100 周期 / 球速 <0.5cm 每周期 → 判争球
- **门球**：进攻方在门区 2 人 / 禁区 4 人停留 20 周期；冲撞守门员 → 防守方门球
- **守门员保护**：守门员在自己球门区不能被进攻方推挤，出区不受保护
- 争球/任意球/开球时摆位必须遵守站位规则（见 `docs/02-平台接口说明.md` 或 01-系统架构中的 formation 说明）
