## 🅲 队员 C：无球进攻（2 项）

### 建议 1：传球权值加「前方威胁」惩罚

**问题**：接应点前方（更靠对方球门一侧）有对手时仍照传，队友接球即被正面压迫 → 传球被断。
**位置**：`src/pass.cpp`（在现有 `count_near_opponent` 后新增函数，评分处修改）
**代码**：

```cpp
// 统计目标点周围「前方威胁」：比目标点更靠对方球门的对手
int count_front_opponent(const WorldModel &wm, double x, double y, double ad) {
    int cnt = 0;
    for (int i = 0; i < PLAYERS_PER_SIDE; ++i) {
        double dx = wm.opp[i].x - x, dy = wm.opp[i].y - y;
        if (dx*dx + dy*dy < THREAT_RADIUS * THREAT_RADIUS) {
            if (ad * (wm.opp[i].x - x) > 0.0) cnt++;   // 前方 = 对方球门方向
        }
    }
    return cnt;
}
```

评分处（plan_pass 内）：
```cpp
int threat = count_near_opponent(wm, tx, ty);
int front_threat = count_front_opponent(wm, tx, ty, ad);
double score = goal_dist + threat * 20.0 + front_threat * 12.0 + pass_dist * 0.5;
```

**要点**：与现有「威胁×20 + 短传×0.5 + 接应点联动站位点」合并，只加前方惩罚；`THREAT_RADIUS=30`。
**验证**：编译通过；实测对方禁区丢球 15→0 次（与 B 围困检测联动）。

### 建议 2：丢球瞬间立即回防（不等状态机滞回）

**问题**：丢球后 1-3 帧 assist/mid 仍停进攻锚点，转换瞬间防守人数不足（实测 demo 反击 12-17 次/场到门前）。
**位置**：`src/roles.cpp` run_assist / run_midfield
**代码**（把条件从 `threat_level > 0.3` 改为）：

```cpp
if (wm.threat_level > 0.3 || wm.no_possession_frames >= 2) {
    DefensePlan dp = plan_defense(wm, id);
    double ty = clamp(dp.target_y + 30.0, 20.0, 160.0);   // assist 封上侧；mid 用 -30 封下侧
    motion::position(wm.home[id], dp.target_x, ty);
    return;
}
```

**要点**：`no_possession_frames` 是状态机已提供的字段（连续无球权帧数），≥2 即视为真丢球，立即回防。

## 🅳 队员 D：防守+工程（3 项）

### 建议 1：防守上抢逼抢

**问题**：防守时我方只站防守点、不压迫持球人，对方从容推进。
**位置**：`src/roles.cpp` run_passive（在 plan_defense 之前插入）
**代码**：

```cpp
void run_passive(WorldModel &wm, int id) {
    const TeamContext &ctx = wm.ctx;
    bool ball_our_half = ctx.attack_dir() > 0 ? (wm.ball.x < 110.0) : (wm.ball.x > 110.0);
    if (wm.team_state == TS_DEFENSE && ball_our_half &&
        !in_penalty_area(ctx, wm.ball.x, wm.ball.y)) {
        double db = dist(wm.home[id].x, wm.home[id].y, wm.ball.x, wm.ball.y);
        int active_id = -1;
        for (int i = 1; i < PLAYERS_PER_SIDE; ++i)
            if (wm.role[i] == ROLE_ACTIVE) { active_id = i; break; }
        double active_d = (active_id >= 0)
            ? dist(wm.home[active_id].x, wm.home[active_id].y, wm.ball.x, wm.ball.y) : 1e9;
        if (db < 60.0 && db < active_d - 5.0) {
            double gx = ctx.our_goal_x(), gy = 90.0;
            double dx = gx - wm.ball.x, dy = gy - wm.ball.y;
            double len = std::hypot(dx, dy);
            if (len > 1e-6) { dx /= len; dy /= len; }
            double px = clamp(wm.ball.x + dx * 12.0, 8.0, 212.0);
            double py = clamp(wm.ball.y + dy * 12.0, 8.0, 172.0);
            motion::position(wm.home[id], px, py);   // 球→门方向 12cm 施压（封前进路线）
            return;
        }
    }
    DefensePlan dp = plan_defense(wm, id);
    motion::position(wm.home[id], dp.target_x, dp.target_y);
}
```

**要点**：只在防守态（状态机）；**禁区内不抢**（禁区纪律）；压迫点距球 12cm ≥ 避球 8cm 规则；比主攻近 5cm+ 才抢（不双人同点）。

### 建议 2：守门员单刀前移

**位置**：`src/roles.cpp` run_goalie，站位深度计算处（只调深度，TTA 预判不动）
**代码**：

```cpp
double guard = kGuardDist;   // 10
if (wm.team_state == TS_DEFENSE) {
    double dmin_opp = 1e9, dmin_our = 1e9;
    for (int i = 0; i < PLAYERS_PER_SIDE; ++i) {
        dmin_opp = std::min(dmin_opp, dist(wm.opp[i].x, wm.opp[i].y, bx, by));
        if (i != id) dmin_our = std::min(dmin_our, dist(wm.home[i].x, wm.home[i].y, bx, by));
    }
    bool ball_our_half = ctx.attack_dir() > 0 ? (bx < 110.0) : (bx > 110.0);
    if (dmin_opp < dmin_our && ball_our_half && std::fabs(ctx.our_goal_x() - bx) < 90.0)
        guard = 18.0;
}
double gx = ctx.our_goal_x() + ctx.attack_dir() * guard;
```

**要点**：单刀（对方最近 + 我方无保护）时站位 10→18cm，扩大扑救覆盖。

### 建议 3（重要）：守门员门前逼抢——治「被推出球门 + 不防带球」

**问题（实测数据）**：demo 带球压到门前时，TTA 只认球速外推、不认「人带球」（vx≈0 不触发）→ 门将只站锚点，被 demo 用身体推出球门（实测门将 x 从 198 被推到 143，离门 77cm）。
**位置**：`src/roles.cpp` run_goalie，在 TTA 判断**之前**插入
**代码**：

```cpp
// 门前逼抢：球在门前 30cm 内 + 有 demo 机器人距球 <15cm（对方持球压门）→ 门将冲球
if (std::fabs(ctx.our_goal_x() - bx) < 30.0) {
    for (int i = 0; i < PLAYERS_PER_SIDE; ++i) {
        if (dist(wm.opp[i].x, wm.opp[i].y, bx, by) < 15.0) {
            motion::position(r, bx, clamp(by, 68.0, 112.0));   // y 夹门宽附近，防追出被吊
            return;
        }
    }
}
```

**要点**：不依赖球速（治带球盲区）；y 夹 [68,112] 防追出球门；与 TTA 预判并存（TTA 处理射门，此处理带球）。
