# 05 · 三人分工方案（按数据流，沿用中型组方案三思想）

> 核心思路：不按"足球角色"分，按"决策链"分——球在谁脚下、怎么走、怎么防。

```
              Strategy::run（每周期）
                    │
    ┌───────────────┼───────────────┐
    ▼               ▼               ▼
 队员A（队长）   队员B           队员C
 "大脑"        "运动+进攻"     "防守+工程"
 world_model   motion(差速轮)   goalie/passive
 situation     shoot           defense
 role_assignment pass          tools/py 调参复盘
 strategy 调度  roles(active/   formation 摆位联调
 formation 摆位  assist/mid)   文档/资格材料
```

| 队员 | 负责文件 | 验收标准 |
|------|---------|---------|
| A | `world_model.cpp` `situation.cpp` `role_assignment.cpp` `strategy.cpp` `formation.cpp` | 角色分配不抖动；12 态摆位在场内；DLL 加载成功 |
| B | `motion.cpp` `shoot.cpp` `pass.cpp` `roles.cpp`(active/assist/mid) | 追球到点误差 <5cm；点球能进；传球不被断 |
| C | `roles.cpp`(goalie/passive) `defense.cpp` `tools/py/*` | 守门不送点球；日志复盘能出报告；调参闭环 |

## 协作约定

1. 每周至少一次合流：跑 `offline_test` + 打一场 demo，更新 `docs/03`
2. 跨模块接口就是头文件里的函数签名，改签名先同步
3. 数值调参（速度/增益/阈值）统一记到 `docs/06-调参记录.md`，不散落在聊天里
4. 每人从自己模块目录起新会话，靠 `docs/03` + AGENTS.md 快速进入状态
