## 这是什么

RoboCup 中国赛 FIRA 小型组 · 仿真 5v5 比赛策略代码。四人小组从零搭建。

- 官方平台 **SimuroSot5**（Windows 仿真程序），策略 = 一个 C++ **DLL**
- 平台每周期传入全场信息 `Environment`（双方 5 机器人、球三帧、场地、比赛状态），策略算完写回 5 个机器人的左右轮速 `vl/vr`
- 产物：`Strategy4Blue.dll`（守右门 x=220，攻左）、`Strategy4Yellow.dll`（守左门 x=0，攻右）

## 关键技术约束

| 约束 | 说明 |
|------|------|
| 32 位 + MSVC | 平台按 C++ mangled 导出名加载 DLL（如 `?RunStrategy@@YAXPAUEnvironment@@@Z`），MinGW 符号不兼容 |
| 文件名固定 | 必须叫 `Strategy4Blue.dll` / `Strategy4Yellow.dll`，放 `C:\Strategy\` |
| 不改接口 | `simuro_interface.hpp` 的 struct/导出函数签名禁止改动，否则加载失败 |
| 无第三方库 | 裸 DLL，不依赖外部运行时 |
| 坐标系 | cm/度，原点左下角 (0,0)，场地 220×180，球门宽 40（y∈[70,110]） |
| 赛制 | 每队 5 人，1 号=守门员；2 半场各 5 分钟；PlayMode 12 种 |

## 目录结构

```
include/simuro5/        策略内核头文件（接口/几何/场地/世界模型/各行为模块声明）
src/                    DLL 导出壳 + 各模块实现
  dll_blue.cpp / dll_yellow.cpp   蓝黄队导出壳（RunStrategy 等 5 接口）
  offline_test.cpp      离线冒烟测试（不依赖平台）
  *.cpp                 各模块实现
docs/                   规则速查/架构/接口/进度/分工/规范/调参/部署/战术库
tools/py/               Python 工具（.rlg 复盘、mark_analysis 跑位分析）
```

## 构建与测试（Windows）

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A Win32 -DBUILD_TEST=ON
cmake --build build --config Release
build\Release\offline_test.exe     :: 冒烟测试（策略 300 帧 + 摆位 12 态）
```
