## 统一传球 Receiving 接球控制规格

输入：`WorldModel&`、当前活动统一传球任务、接球人状态、球位置与球速；
距离单位 cm，速度单位 cm/帧，角度单位度。

输出：只写锁定接球人的 `vl / vr`，不修改 `receiver_id / rx / ry` 或生命周期判据。

规则：

1. Preparing 始终沿用 `motion::position(receiver, rx, ry)`，不得减慢前期跑位。
2. Receiving 且球距接球人不小于近距半径时，也沿用同一普通赶路命令。
3. Receiving 且球进入近距半径后，锁点保持不变，但动作优先级切换为“先面向来球、再补锁点位置”。
4. 近距平移速度按球距连续缩放，只缩放左右轮共同前进分量，保留差速转向分量。
5. 球速有限、处于可信范围且速度投影表明确实朝接球人逼近时，机头朝球速度反方向。
6. 球速太小、非有限、异常过大或没有逼近时，优先朝当前球位置。
7. 对正后，仅当锁点位于机头前后可直行/倒行的角度内才低速补位；侧向锁点暂时停车迎球，差速车不尝试横移。
8. 球与接球人位置也退化时，使用锁定传球方向的反方向；仍无效则保持当前朝向。
9. Ordinary 与 Coop 共用 `run_pass_receiver()` 内同一行为；Received 后继续现有临时控球。

边界：非法球距不执行接球定向，退回现有锁点走位；取消、超时和接稳判据保持不变。

验收：覆盖 Preparing 不变、Receiving 远距不变、近距减速、正面/侧面来球、
极小与异常球速兜底、成功接稳、失败超时，以及 Ordinary/Coop 行为一致。

非目标：接球后射门、连续传球、二过一、动态轨迹截击、重新选人或重新选点。
