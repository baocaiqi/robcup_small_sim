# 工具与测试

## 构建（Windows + VS2022 BuildTools）

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A Win32 -DBUILD_TEST=ON
cmake --build build --config Release
```

产物：`build/bin/Release/Strategy4Blue.dll`、`Strategy4Yellow.dll`、`offline_test.exe`

**为什么必须 MSVC 32 位**：平台按 C++ mangled 导出名（`?RunStrategy@@YAXPAUEnvironment@@@Z`）LoadLibrary 加载，MinGW 符号命名不兼容。

## 部署

```bat
copy build\bin\Release\Strategy4Blue.dll C:\Strategy\
copy build\bin\Release\Strategy4Yellow.dll C:\Strategy\
启动 SimuroSot5.exe
```

文件名必须保持 `Strategy4Blue.dll` / `Strategy4Yellow.dll`。

## 离线测试（offline_test.exe）

不依赖平台：
- 策略 300 帧冒烟（跑完整流水线，校验无崩溃/无 NaN）
- 摆位 12 态（全部 PlayMode 死球摆位）

用法：`build\Release\offline_test.exe`。改代码必跑。

## Python 工具（tools/py/）

| 工具 | 用法 | 作用 |
|------|------|------|
| rlg_analyzer.py | `python tools/py/rlg_analyzer.py 日志.rlg` | .rlg 复盘：逐帧快照、CSV 导出、统计报告 |
| mark_analysis.py | `python tools/py/mark_analysis.py <rlg>` | 跑位/盯人分析：标记威胁、逼近速度、球危险速度 |
| geometry.py / constants.py | import | 与 C++ 镜像的几何/常量，用于离线复算验证 |
