## 与 cbm 图谱差异

| | cbm（codebase-memory） | ua（understand-anything） |
|--|--|--|
| 定位 | 结构化代码查询（调用图/热力/影响面） | 语义知识图谱（分层/tour/文档关系） |
| 查询接口 | MCP search_graph/trace_path/query_graph | 读 JSON + dashboard 交互 |
| 文件 | .codebase-memory 缓存（~/.cache） | `.ua/knowledge-graph.json` |
| 增量 | detect_changes / re-index | 按 commit 增量更新 |
| 谁消耗 token | 索引本地跑，仅查询耗会话 token（低） | 全 LLM 管线（扫描/批量分析/分层/tour/审查），token 高 |
