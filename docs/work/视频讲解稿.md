## 二、连续讲解词（配音连读版）

各位评委好，我们是 Hnnu 队。下面用两分多钟，展示我们的 5v5 仿真足球策略系统：先说总体设计框架，再用真机比赛画面说明它怎么踢。

这是系统的总体框架。平台每秒把全场状态交给我们 40 次，每次 25 毫秒，我们回一次五个机器人左右轮的速度。

每帧只做三件事：读世界、判局势、派活。最关键的是角色固定分工——门将、主攻、助攻、中场、后卫各守其责，不做每帧抢球权式的改写，所以站位稳定，不会出现两个人抢同一个球、门前没人。

进攻上，第一件事是判断"能不能射"。我们把球门看成扇面，算出门张角、再扣掉守门员挡住的那一块，剩下的叫净开口，瞄的就是净开口最宽处。

射不进去就换个角度：我们加入了借墙射门——球先打边墙、反弹后进门。注意这个平台反弹不是镜面反射，我们扫了 118 场真机录像量出参数：垂直墙的速度只剩 66%、顺着墙的剩 81%，所以反弹点是解方程算出来的，不是简单镜像。

防守分两层。门将先按球的速度外推到门线，算球会从哪个位置进门；球已经飞在门框范围内时，直接抢门线上的落点；如果球比门将更靠门，门将先横向让开，避免用身体把球顶进自家球门。

其余四人分层：后卫站在球与球门的连线上、球门前 50 厘米处等球，赶不上就退回门前；威胁高时改成人盯人，盯谁用四项打分决定；对方带球压上就二抢一，射门打出就抢二次落点。

定位球是我们花功夫最多的地方。平台把比赛分成 12 种状态，每种状态都要我们自己摆位：开球、任意球、门球由主罚方先摆，点球由防守方先摆。执行的时候平台不告诉我们"这是点球"，我们靠"球静止停在罚球点上"识别出来，然后就地转正、立刻出脚，不做多余的倒车。

还有一条容易被忽略但很值钱的线：纪律。门区聚集、在角区推球、死球期间碰球都会被判罚，所以这些不是"注意事项"，而是写进策略里的硬约束——该不碰球的时候就绝不碰。

这是真机比赛的实时画面。可以看到我们的机器人在门前保持层次、丢球后立刻回收、重新控球后反击前插。

## 五、配音有哪几条路（按省事程度排）

| 途径 | 怎么做 | 成本 | 适合 |
|---|---|---|---|
| **① 剪映「文本朗读」** | 把 mp4 拖进剪映 → 文本 → 粘贴本稿讲解词 → 朗读 → 选音色（"解说小帅""译制片男声"等）→ 导出 | 免费、0 门槛、10 分钟出片 | **最推荐**，不想露声就选这条 |
| **② 自己念 + 剪映录音** | 剪映里"音频 → 录音"，对着分镜表念（每个时间段只有 1~3 句，很好对） | 免费，需要安静环境 + 麦克风 | 想有真人味、又不请人 |
| **③ 系统自带录音机** | Win 搜索"录音机"（Voice Recorder）录 m4a → 我帮你用 ffmpeg 并进 mp4（一条命令） | 免费 | 你已经有素材、不想开剪辑软件 |
| **④ edge-tts 自动配音（我可以代跑）** | `pip install edge-tts` → 我按本稿生成中文旁白 mp3 → 直接并进成片，**你只审听** | 免费，需要联网 | 你想省掉全部配音工作 |
| **⑤ 请人配** | 淘宝/配音平台搜"宣传片配音"，几十元，2 分钟成片通常 ¥30~80 | 几十元 | 想要专业播音质感 |

**并音轨的命令**（途径③/④/⑤ 拿到音频后用；我也可以直接帮你跑）：

```bat

```

> 注意：成片**没有音轨**，所以配音从 0:00 开始就是对齐的；若你的旁白比 2:38 长，

## 六、真机实测录像怎么来（要融进片子）

三条路，任选：

1. **用我写的脚本（推荐，最省事）**：先把平台跑起来、把球场窗口拉到合适大小，然后
   ```bat
   python tools\py\record_platform.py --list          :: 看窗口标题
   python tools\py\record_platform.py --seconds 90 --out build\real_match.mp4
   ```
   它抓 `WorldModel` 球场窗口、直接编码成 mp4（不需要装 OBS）。
   录完再出一条带真机画面的成片：
   ```bat
   python tools\py\make_video.py --rlg "C:\Strategy\你的.rlg" --real build\real_match.mp4
   ```
2. **Win+Alt+R（Xbox Game Bar）**：系统自带，按一下就录当前窗口/全屏，文件在 `视频\捕获`；
   录完把 mp4 路径给我，我剪进去。
3. **OBS**：功能最强但要装；如果你以后还想录别的素材，值得装。

**录的时候注意**：① 先按 `--list` 确认标题；② 平台窗口别被别的窗口挡住（抓屏抓的是屏幕该区域）；
③ 想录"点球/进球"这种关键时刻，提前 5 秒开始录；④ 录 60~120 秒足够（片子里只用 20 秒）。

## 四、录制常见坑

1. **平台球场窗口太小** → 录之前拉大窗口，或录完用剪辑放大关键区域；
2. **文件超 10MB** → 用两遍 H.264（CRF 26~28）、720p、无背景音乐（或 48kbps 轻音乐）；
   平台画面大多是静态色块，压出来通常远小于 10MB；
3. **别只放录像不讲解** → 评委要听"设计思路"，讲解词必须覆盖框架与策略，不能只报比分；
4. **别出现他人代码/他人的界面** → 全程只展示我们自己的策略与平台自带的仿真环境。
