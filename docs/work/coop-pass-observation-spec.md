# CoopPass 连续比赛观测规格（2026-09-21）

- 目的：只记录当前行为；普通 PassPlan、CoopPass 判断顺序、动作和全部阈值保持不变。
- 构建前提：HEAD 调用了不存在的 mark_engage_threat/retreat_threat；恢复 60989d2 已有 0.6/0.3，单独披露。
- 输入：WorldModel 中任务、临时控球、球与双方位置；sim_bench 每场固定种子、完整 24000 帧。
- 输出：每队任务创建/出球/接稳/临时权计数；互斥主要结果和取消原因；按任务及逐帧 CSV 供复盘。
- 主要结果：成功、准备超时、接球超时、截球、各类取消、比赛末未完成（右删失，不能算失败）。
- 同任务出球/接稳/临时权只能各计一次；成功后临时权失效是次级结果，不能再算一次传球失败。
- 安全取消保持原短路顺序，分别记录比赛状态、无效球、点球、高威胁、角区、截球、紧急护门、门内来球、参与者纪律、目标非法、接应点贴身、线路失效、准备点非法等。
- 所有直接取消入口都需挂统计，未创建时取消不得增加计数；模拟器瞬移另外标记，仅诊断不干预。
- 观测字段覆盖阶段年龄、推动观察、位移/速度投影/球人分离、接球距离/速度/连续证据、临时权持续帧数、中威胁接应、主攻轮速。
- 仿真物理触球/携带记录与策略确认分开，碰球不等于接稳；不能根据几何接近直接宣布真接稳或误判。
- 单位：物理速度 cm/s 乘 kDt 后以 cm/帧记录；策略球速为输入球位差分，不能混用。
- 默认输入存在球位历史覆盖问题，正常帧策略球速为零；额外提供显式 --correct-ball-history 实验，保存推进前球位、复位时对齐历史，不改默认行为或物理。结果与默认组分开，不据此直接调参。
- 验收：指定构建与两套离线测试；统计守恒/重复取消/成功后取消回归；有无观测固定种子比赛指标一致。
- 样本：三模式先各 20 场验证统计，再各 50 场独立种子序列；self 两队分开记录，避免口径混合。
- 统计原始产物保留到 docs/work，结果及模型限制写报告，docs/03、docs/06 只追加简要进展，不改提交材料。
