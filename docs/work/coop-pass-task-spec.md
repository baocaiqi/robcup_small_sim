# CoopPass 统一接球任务规格

- 输入：WorldModel 当前球位、球权、比赛状态、安全约束；CoopPass 接球人及厘米坐标。
- 输出：WorldModel 内保存 active、阶段、passer_id、receiver_id、rx/ry、剩余帧数、发布时比赛状态及出球/接球观察证据；另保存接球完成后的临时带球权。
- 仅主攻通过配合传球选择、安全检查及准备点检查，进入对准/推球执行后发布任务。
- 有效任务固定接球人和目标；准备阶段主攻按当前球位重新计算指向保存目标的方向，不重新评分选人。
- 指定接球人优先执行同一目标，不受普通避敌、分散及队友间距覆盖；其余队员不变。
- 保留紧急护门、高威胁回防、点球、角区禁推及门区纪律优先级。
- 超时（80 次主攻执行，约两秒）、比赛状态变化、明确对手控球或危险时取消；准备阶段另检查传球线路/接球点安全，取消帧不重新发布。
- 短暂无人控球及单纯攻防状态翻转不取消，避免球飞行时接球人跑回普通站位。
- 主攻入口在所有早退前扣一帧并推进观察，各角色执行前检查安全；飞行/带球让位停车前照常维护门区计数及射门冷却，超限照常撤离，调度纪律覆盖参与者动作时取消。
- CoopPass 绕过射门次数上限，不增加射门计数；普通射门次数限制及 PassPlan 保持原样。
- 出球后生命周期（本轮）：准备/推动、已出球接应、已接球三个阶段；接球完成时 active=false，另授予接球人临时带球权，固定编号角色不变。
- 发出推球指令只记录观察起点，后续主攻帧须同时观察到沿传球方向位移≥6cm、速度投影≥1cm/帧、球离传球人≥14cm且位于其前方，才转入接应。观察起点只在贴球推动时记录一次。
- 飞行阶段先观察出球再复核阶段安全，不再重算当前球到接球点的挡线/贴身条件；保留明确截球、危险、纪律、比赛切换和80帧总超时。
- 飞行中1号停止重复推这脚球并停车让位；接球人继续跑锁定点，不因 no_possession_frames 增长或0.3≤威胁<0.6的普通回防而离开。
- 接球要求连续2帧球距接球人<12cm、接球人是最近己方且对手更远，并有己方球权或明显距离优势（领先对手5cm）；球速≤3cm/帧，避免把高速掠过当控住。
- 接球完成当帧由2～4号接球人继续处理球：临时带球权优先于普通跑位，使用已有运动控制转正/绕球后向合法前方带球；不调用普通PassPlan、不修改评分或射门质量。
- 临时带球期间1号让位；球已由其他队友明确控制、连续3帧离接球人>20cm、明确对手控球或安全/比赛状态变化时撤销临时权，恢复固定角色调度。
- 新增阈值须后续仿真/真机标定；连续帧测试验证未推出不报成功、真实出球后不重推、不按飞行线路误取消、截球取消及成功接球后的实际处理动作。
- 验收：专用测试覆盖不同普通跑位目标、三种接球角色、跨帧锁定、取消恢复、射门额度耗尽仍传、安全检查不发布。
- 执行：offline_test --coop-pass-only 及全量 offline_test，保留已有断言。
