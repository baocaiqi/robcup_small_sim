## 统一传球等待期对手抢点取消规格

输入：`WorldModel&` 中当前活动 `coop_pass_task`、锁定的 `receiver_id / rx / ry`、
接球人位置，以及五名对手的位置和速度；距离单位 cm，时间单位帧。

输出：不改变选人、选点或评分；仅在满足条件时通过 `coop_finish(OpponentFirst)`
结束当前统一传球任务。

规则：

1. 普通 `PassPlan` 与 `CoopPass` 共用 `cancel_unsafe_pass_task()` 内同一判断。
2. 先执行现有安全规则并保留其取消原因优先级；仅在现有规则均安全后补判抢点。
3. 仅 `Preparing`（球尚未确认出脚）阶段判断；`Receiving / Received` 不判断。
4. 接球人时间使用锁点距离除以固定接球估计速度，不改 readiness gate 参数。
5. 对手时间取五人最小值；先按当前速度朝锁点的投影短期外推，再按固定跑速估剩余路程。
6. 朝锁点运动会缩短时间，背离锁点会增加时间；速度无效或尚无速度历史时按静止处理。
7. 仅当 `最快对手时间 + 安全余量 < 接球人时间` 时取消；等号及接近情况继续等待。
8. 非有限坐标、非法接球人或非法估计参数不触发本规则，交给既有安全规则处理。

验收：覆盖对手明显先到、接球人明显先到、时间接近、对手高速远离、
等待后对手转为明显先到、以及进入 `Receiving` 后不再取消；两种任务类型均走同一入口。

非目标：动态传球线路截击、接球朝向、减速接球、路径规划，以及
`plan_pass()` / `plan_coop_pass()` 的候选与评分公式。
