## 一、现在的防守策略是什么（代码口径）

**角色固定**（`role_assignment.cpp`）：`0=GK`、`1=ACTIVE`、`2=ASSIST`、`3=MID`、`4=PASSIVE`。

**三层决策**：

1. **全局态势**（`situation.cpp` + `strategy.cpp`）：威胁分级 → 攻防态滞回 3 帧翻转 → 双锚点（进攻/防守）
   推给无球队员；方案 C 的"非门将门区停留 >15 帧撤出 + 30 帧冷却"兜底。
2. **区域防守工具箱**（`defense.hpp/cpp`，队员 D 负责）：
   - `predict_y_at_x` 直线外推 / **`predict_y_at_x_reflect` 带边墙反射**（球撞 y=0/180 后折返）
   - `intercept_point`：球**真实轨迹** ∩ 门前拦截线 → 断球点（**用了反射版**）
   - `plan_defense`：2 号防守者断球点（含"我赶不赶得上"的可达性判断）
   - `goal_cover_point`：球-门连线护门点（参考官方 demo 中卫思想自研）：球距门 >100 → 球向门 45cm；
     45~100 → 门前 50cm 线跟球；<45 → 门前 20cm 线跟球
   - 人盯人：`mark_threat` 打分 + `pick_mark_target`（10% 滞回 + 危险门限 40cm）+ 预测外推 3 帧 +
     40cm 内改堵传球线；`double_team_point` 二抢一夹击；`rebound_point` 抢反弹位（球朝门速 >8 才算）
3. **门将 `run_goalie`（roles.cpp）按优先级**：
   ① 点球→锁门线中央 ② 球距门<45 且球静止→穿球推出去 ③ 对方持球压门（<45 且对方离球<25）→
   站球-门连线封角 ④ 球距门<20→清给"最空队友"（防乌龙加侧向偏移）⑤ 二过一威胁→后退封门
   ⑥ 近距扑球：`on_target && tta<15 帧 && 够得着(<30cm) && 朝门速>5` → 扑门线内预测点；
   **若预测点离自己 >30cm → 赌近门柱（固定 74 / 106）** ⑦ 远射/带球→按球速动态前压
   （深度 = 门前10 + 比例×(80−10) − 埋伏人数×20）⑧ 否则门前 10cm 站线、y 跟球。

## 二、你报的"墙边推球过来"为什么漏（三个缺口）

1. **门将的预测不含边墙反射**：`run_goalie` 用的是 `predict_y_at_x`（直线），而工具箱里的
   `predict_y_at_x_reflect` **只给后卫用**。球贴边墙滚/即将撞墙时，直线外推会把落点算到界外或错侧
   → `on_target` 判错、`iy / y_at_goal` 偏 → **门将站错边**，看起来"完全没意识"。
2. **近门柱只在"已判定在门框内"时才赌**：条件 `on_target && |y_at_goal−90| > kMaxReach(30)`，
   且用**固定 74/106**——既不区分"哪一侧来球"，也在算错 `y_at_goal` 时整个不触发。
3. **没有可达性判断**：`out_x / iy` 是几何理想点，没算门将"赶不赶得上"（制动包线口径下
   `t_move(de) ≈ de/1.75 + 10 帧`）。赶不上时不会提前改封近角 → 观感就是"慢半拍"。

## 三、方案（三项，最小改动，逐项可验证）

**P0 换预测（几乎免费）**：门将改用 `predict_y_at_x_reflect` 算 `y_at_goal`，`tta` 也按反射后路径算。
→ 墙边来球的落点不再算错，`on_target` 判定直接变准。

**P1 墙边来球 → 封对应门框边（你的主诉）**
- 触发（满足任一）：
  - 球贴边墙：`by < 25` 或 `by > 155`，且球朝我方门（vx 朝门），且球距门 < 120cm；
  - 反射预测落点在门框附近外侧：`|y_at_goal − 90| ∈ [20, 45]`（贴着门柱/擦柱而出）。
- 动作：`aim_x = 门线 + 3cm`（贴线，不给角度），`aim_y = 近门柱 ∓ 4cm`：
  - 近侧由**来球方向**决定：`by < 90`（或 `vy < 0`）→ 走**下门柱侧** `y = 76`；否则 `y = 104`。
  - 依据：门柱内侧 4cm 是最容易漏的一条带（真机复盘已有"上角 y∈[100,105]"丢球史），
    贴柱站位让身体+滑移覆盖柱内侧；而现在的 74/106 是按 `y_at_goal` 偏差硬选，方向常选反。
- 与现有分支的关系：插在 ⑥ 近距扑球**之前**判断"是否墙边来球"，命中则封柱；否则走原逻辑。

**P2 轨迹预测 + 可达性（"快速防守"）**
- 到达时间模型（与 motion 制动包线同口径）：`t_move(de) ≈ de/1.75 + 10`（帧；70cm/s 巡航 + 末段 ~10 帧）。
- 决策：
  1. `t_move(de→理想拦截点) ≤ tta − 2` → 去理想点（现状）；
  2. 否则 → **提前改去可达的保守点**：门线上、按来球侧的近门柱（比理想点近、且保命）；
  3. `球距门 < 35cm 且 tta < 8 帧` → 直接扑门线，不等"对齐/清球"分支。
- 新常量集中在 `run_goalie` 顶部（`kWallSideDist=25`、`kPostCoverMargin=4`、`kCruiseFrames=1.75`、
  `kTailFrames=10`、`kCommitTta=8`），便于标定与一键回退。

## 九、P5：墙边封球提速（2026-09-12 09:5x，用户指令"墙边封球速度不够快"）
