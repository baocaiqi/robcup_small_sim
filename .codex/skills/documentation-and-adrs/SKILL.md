# Documentation & ADRs — 文档与决策记录

## 规则
- 重要决策写 ADR：背景 → 选项 → 选择 → 原因（3-8 行）
- 现有 ADR 见 docs/01-系统架构与开发指南.md「关键设计决策」表，新增往上加
- 调参数值只认 docs/06-调参记录.md，聊天里的不算数
- 进度只认 docs/03-开发进度跟踪.md

## 决策模板
```markdown
| 决策 | 原因 |
|------|------|
| <我们选了 X> | <为什么> |
```

## 维护约定
- 每次改头文件接口 → 更新 docs/04 算法详解 + 通知相关队友
- 每周 → docs/03 进度更新一次
- 新增模块 → 在 README 目录结构补一行
