# Context Engineering — 上下文管理

## 3 人小团队的实际问题
- 仓库小（43 文件），但 AI 会话历史会拖垮上下文
- 每人只关心自己模块，别把全仓库塞进上下文

## 做法
1. 新会话从模块文件开始点名：
   `先读 docs/03 进度 + docs/06 调参 + <我的模块头文件>，然后…`
2. 关键结论立刻写入 docs/03（问题日志）或 docs/06，不靠记忆
3. 会话太长（>1 小时）→ 开新会话，带 docs 引用
4. 全仓库搜索用 file-search skill（不整文件读）

## 本项目"必读三件套"（每个新会话）
- docs/03-开发进度跟踪.md（现在到哪了）
- docs/06-调参记录.md（参数现状）
- 你的模块头文件 + AGENTS.md（约定）
